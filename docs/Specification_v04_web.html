01. Deployment & Distribution Architecture

Production Build Access & Bad Actor Mitigation
  • Authenticated Access: Downloads and active client sessions are strictly restricted to authenticated, logged-in web accounts.
  • HWID & Account Fingerprinting: Session tokens are tied to Hardware ID (HWID) hashes upon launch to prevent banned users from bypassing restrictions with alt accounts.
  • Signed URLs & Watermarking: Builds are distributed via short-lived, user-signed Node.js download URLs. Dynamic account telemetry is embedded in client binaries for leak tracing.
  • Server-Side Behavioral Telemetry: Real-time log routing from game instances to the web API flags network anomalies, memory tampering, and griefing behavior.
Developer Sandbox Deployments
  • Contributors can trigger automated deployments of any active git branch directly to the online sandbox environment based on role-based repository permissions.

02. Contributor & Asset Creation Workflow

End-to-End Asset Generation & Sync Pipeline

Step-by-step user journey for artists and developers creating game-ready assets through the web portal.

1
Authentication & Web Hub Session

Contributor logs into the private developer portal using 2FA. SSO handles session authentication and unlocks Git repository permissions automatically.

2
Image Reference Ingestion

Contributor uploads concept/reference images (e.g., photo, sketch, AI generation) through the portal UI. Files are stored securely in Cloudflare R2.

3
Automated 3D Reconstruction & Mesh Generation

The portal triggers a serverless GPU job (RunPod). Vision models tag the object while Trellis/Rodin converts the reference image into a raw high-poly 3D wireframe mesh.

4
Web Visual Inspection & Approval

Contributor previews the wireframe, texture, and generated LOD chain directly inside an interactive 3D WebGL viewer within the portal.

5
Automated Repository Commit & Multi-Tool Distribution

Upon approval, the pipeline packages the asset (`.FBX` / `.GLB`), generates the vector search embeddings, and auto-commits the files directly into GitHub LFS on the target dev branch.

6
DCC & Engine Access (Blender / Unreal Engine)

Artists run git pull or launch the custom UE Python plugin. The asset immediately populates in the Blender project tree and Unreal Engine Content Browser, fully rigged or formatted for placement.

04. Developer Portal & Ingestion Pipeline

Developer Hub Communication

Integrated real-time Skype-style voice/text chat built directly into the private contributor web portal.

Automated Multimodal Ingestion Pipeline
[Uploaded Reference Image] │ ├───> 1. Vision Tagging Engine (Qwen2.5-VL / Gemini Flash API) │ └─> Structured metadata JSON (lighting, time of day, surface detail) │ ├───> 2. Vector Embedding Engine (CLIP / SigLIP - CPU/Worker) │ └─> 512-d Vector stored in Qdrant Cloud / Supabase pgvector │ ├───> 3. Serverless AI Image-to-3D Reconstruction (Trellis / Rodin API) │ └─> Raw High-Poly 3D Mesh (.FBX / .GLB) via RunPod Serverless │ └───> 4. Auto-Retopology & LOD Processor (Blender Headless / Simplygon) ├─> Low-poly clean wireframe mesh (LOD0) ├─> Automated LOD chain generation (LOD1 – LOD4) └─> Auto-commit to GitHub (Git LFS) for Unreal Engine deployment
Multimodal Asset Query & Retrieval Logic
  • Direct Match Similarity ≥ 0.82: Returns exact visual, texture, and wireframe matches.
  • Partial Match Similarity 0.55 – 0.81: Returns nearest visual approximations and reference fallbacks.
  • No Match Similarity < 0.55: Triggers prompt: "Nothing like this exists in the asset collection."

05. Execution Methodology & Low-Cost AI Hosting

Infrastructure Deployment Strategy (Zero-Idle Compute Target)

To preserve workstation GPU hardware for Unreal Engine development and eliminate recurring idle server costs, all pipeline workloads are hosted on decoupled, pay-per-execution cloud infrastructure.

Pipeline Stage Deployment Provider Execution Mechanism Cost Target
Image-to-3D Gen & Retopology RunPod Serverless / Modal Pay-per-second Docker container spin-up (RTX 4090/A6000) for mesh runs. Scales to zero when idle. ~$0.01 / mesh
Vision Tagging Engine Gemini Flash API / Ollama Cloud Managed REST API calls for automated visual feature extraction & lighting analysis. $0.00 (Free Tier)
Vector Embeddings (CLIP) Node.js / Python CPU Worker Lightweight ONNX CPU execution during asset upload. No dedicated GPU required. $0.00
Vector Search Database Qdrant Cloud Free Tier Managed vector index storing up to 100,000+ asset embeddings in 1GB memory limit. $0.00 / month
Asset Storage & Egress Cloudflare R2 Object storage for raw assets, temporary GLB files, and textures. Zero egress bandwidth fees. $0.00 (10GB Free)
