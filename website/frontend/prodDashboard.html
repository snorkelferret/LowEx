Game store

Everything the studio has approved for the game, including work by other developers. Import takes a copy into your own workspace to work on; Download gives you the files, with a manifest saying what they are.
Download asks which folder these belong in, and the button on that folder dialog says Upload. That word belongs to the browser, not to this page — reading a folder is the one thing a browser only knows how to do with its upload control, so every site's folder picker says it, whatever the site is doing.
No file ever leaves your machine. Your folder is read here, in this browser, to see which files you already have. The only thing sent to the server is a list of hashes — sixty-four characters for each file you are missing, and nothing else. That list is what tells the server which files to put in the zip. A version of a thousand files you already have sends a thousand short lines of text and no content at all.
